Review all Personal Access Tokens for your account.

## Goal

Find active tokens and verify which one is being used.

## What you see

- Every Personal Access Token you own, with its status and last use
- A way to open a token for details or jump to revoke it

## Using Devopness MCP

Try these prompts in Devopness MCP:

- "List my personal access tokens."
- "Show me which of my personal access tokens are expiring soon."

## Verify

- You can see all Personal Access Tokens you own
- You can identify which token is still active and which is revoked

## Common issues

- The list is empty: create a token first
- A token is missing: confirm you are using the right account
